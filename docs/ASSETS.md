# Asset bên ngoài

**Kiểm kê Phase 7 (2026-10-11):** skin giao diện đang dùng từ bộ dưới đây. Map, bụi, vòng bo, đạn và hiệu ứng ánh sáng được vẽ bằng code Phaser/CSS của dự án; không có gói sprite thương mại mới. Khi thêm asset ở phase tiếp theo, ghi nguồn, giấy phép, file dùng và vị trí hiển thị tại đây trước khi phát hành.

## Kenney UI Pack 2.0

- Nguồn: https://kenney.nl/assets/ui-pack
- Giấy phép: Creative Commons Zero (CC0 1.0), xem `client/public/assets/ui/License.txt`.
- File dùng: sáu ảnh nút PNG và `Kenney Future.ttf` trong `client/public/assets/ui/`.
- Ứng dụng: nút trang đầu, HUD, chọn vũ khí, nút bắn và logo. Font Kenney chỉ dùng cho logo; nhãn tiếng Việt dùng font giao diện để giữ dấu rõ ràng.

Chỉ các file đang dùng được đưa vào repo. Bản ZIP đầy đủ nằm ở thư mục tạm `.runtime-test` và không cần để chạy game.
